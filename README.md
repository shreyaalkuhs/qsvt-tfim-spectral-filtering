# QSVT spectral filtering for the TFIM

This repository contains the Erdős Institute Quantum Computing Bootcamp mini-project on using quantum signal processing (QSP) and quantum singular value transformation (QSVT) as a spectral filter for the transverse-field Ising model (TFIM).

The notebook follows the project in the order it was developed:

1. construct and diagonalize a two-qubit TFIM;
2. shift and normalize the Hamiltonian into the QSVT interval;
3. construct and verify a signal-unitary block encoding;
4. optimize QSP phases that suppress the excited-state spectrum;
5. lift the scalar QSP response to matrix QSVT and verify the selected block;
6. apply the filter to a trial state and measure ground-state fidelity and postselection probability;
7. generalize the dense small-system calculation to arbitrary TFIM size;
8. analyze the Pauli/LCU resource scaling for larger systems.

## Model and qubit ordering

The open-boundary TFIM is

```text
H = -J sum_j Z_j Z_{j+1} - g sum_j X_j.
```

Pauli strings use Qiskit's ordering convention: the **rightmost character acts on qubit 0**. For example, `IZZ` represents the interaction `Z_0 Z_1` in a three-qubit register.

## Resource interpretation

The explicit block encoding used in the notebook is a dense small-system validation tool. For an open `n`-qubit TFIM, the Hamiltonian itself contains only `2n - 1` nonidentity Pauli terms, or `2n` terms after including the energy shift. A scalable implementation would use that sparse Pauli structure in an LCU-style block encoding rather than constructing a dense matrix.

For a degree-`d` QSVT sequence, the logical query count is `d` block-encoding calls. With a straightforward SELECT decomposition, the number of term-select branches scales as `O(d n)`.
